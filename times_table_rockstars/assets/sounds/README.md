# Sound Assets

Place your sound effect files in this directory:

- `correct.wav` - Sound when answer is correct
- `incorrect.wav` - Sound when answer is incorrect
- `coin.wav` - Sound when earning coins
- `complete.wav` - Sound when completing a game
- `click.wav` - Button click sound

## Generating Sounds

You can:
1. Use free sound libraries like freesound.org
2. Generate using tools like SFXR or BFXR
3. Record your own sounds

## Recommended Sources

- **Freesound.org** - Free sound effects with Creative Commons licenses
- **BFXR** (https://www.bfxr.net/) - Browser-based sound effect generator
- **Zapsplat** - Free sound effects library

## Format

- Format: WAV or OGG
- Sample rate: 44100 Hz recommended
- Keep files small (< 500KB each) for mobile performance
