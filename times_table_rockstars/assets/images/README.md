# Image Assets

This directory stores image assets for the game.

## Files Needed

### Icons and Graphics
- `icon.png` - App icon (512x512 recommended)
- `presplash.png` - Splash screen shown on app launch
- `avatar_default.png` - Default avatar image

### Background Images (Optional)
- Rock star themed backgrounds
- Stage/concert imagery
- Musical instruments

## Avatar Images

Users can set custom avatars from:
1. URLs (via the avatar customization screen)
2. Local image files
3. Default placeholder images

## Image Format

- Format: PNG (with transparency) or JPG
- Keep file sizes optimized for mobile
- Use web-friendly dimensions (max 1024x1024 for most images)

## Sources for Free Images

- **Unsplash** (unsplash.com) - Free high-quality photos
- **Pixabay** (pixabay.com) - Free images and graphics
- **Pexels** (pexels.com) - Free stock photos
- **OpenGameArt** - Free game graphics

## Custom Avatar Feature

The app allows users to input any image URL to use as their avatar.
This enables personalization without bundling many images with the app.
